【目標】
用已經係 Live 狀態嘅 Meta App「HermesfBpost」（App ID 1096613296209830），產生一個 Firebean Facebook 專頁（Page ID 117038204973135）嘅 Page Access Token，並貼去指定 Google Sheet。

【步驟】
1. 開 https://developers.facebook.com/tools/explorer/
2. 右上角「Meta App」下拉選單 → 揀「HermesfBpost」（App ID 1096613296209830）
3. 撳「Permissions」下拉 → 加入以下權限（逐個揀）：
   pages_show_list
   pages_manage_posts
   pages_read_engagement
   business_management
4. 撳「Generate Access Token」掣 → 彈出授權視窗 → 全部撳「繼續 / 允許」
5. 喺中間查詢輸入框，清空原有內容，輸入：
   me/accounts?fields=id,name,access_token
6. 撳右邊藍色「Submit」掣
7. 下方會出 JSON。喺 data 陣列入面搵 name 等於 "Firebean"、id 等於 "117038204973135" 嗰個 object，複製佢 access_token 嘅完整字串（好長，EAA 開頭）
8. 開 https://developers.facebook.com/tools/debug/accesstoken/ ，貼入去，撳「Debug」，睇「Expires」一欄：
   - 如果顯示 Never → 好，繼續第 9 步
   - 如果顯示一個日期 → 唔好繼續，直接跳去同我報告
9. 開 https://docs.google.com/spreadsheets/d/1EmZB3WecmKIL7TTHGeJzohLTDKhUMPxBSrGv8mwRE28/edit
   揀「Token」工作表，將個 access_token 貼落 A2 一格（純文字，唔要引號、唔要空格）
10. 完成後回報我：「已完成，Expires 顯示 Never」（或顯示嘅日期）
