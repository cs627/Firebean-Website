Copy & paste setup — 2 files only, no zip, no download.

How to install (5 minutes)
  1. Open your Google Sheet → Extensions → Apps Script
  2. Click Code.gs in the left sidebar, select everything (Ctrl/Cmd + A), delete it, then paste the Code.gs below
  3. Click + next to Files → HTML → name it exactly Index → select everything, delete it, then paste the Index.html below
  4. Press Ctrl/Cmd + S to save
  5. Deploy → Manage deployments → pencil icon → Version: New version → Deploy
⚠️ Before going live: in Code.gs line ~30, change DRY_RUN : true to DRY_RUN : false. While it is true the app will not send emails or create calendar events.
