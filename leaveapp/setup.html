How to install (5 minutes)
  1. Open your Google Sheet → Extensions → Apps Script
  2. Click Code.gs in the left sidebar, select everything (Ctrl/Cmd + A), delete it, then paste the Code.gs below
  3. Click + next to Files → HTML → name it exactly Index → select everything, delete it, then paste the Index.html below
  4. Press Ctrl/Cmd + S to save
  5. Deploy → Manage deployments → pencil icon → Version: New version → Deploy
  6. If anything looks wrong, run diagnose in the editor — it prints the running build, DRY_RUN state, which Sheet/spreadsheet the script is bound to, the resolved calendar name, your email quota, and the last 5 requests
  7. Run the built-in self-test (see below) to prove email + calendar work ✅
  8. Check the two settings near the top of Code.gs: CALENDAR_NAME : 'Firebean Team' (leave events land on that calendar) and CALENDAR_GUESTS : 'requester'
  9. When you change someone's Annual Entitlement in the Staff sheet, run syncEntitlementHistory to log it (starts in preview mode)
  10. Optional: run backfillCalendar to push old already-approved leave onto the calendar. It starts in preview mode (DRY = true) — read the log, then flip to false.
⚠️ Before going live: in Code.gs, near the top, change DRY_RUN : true to DRY_RUN : false. While it is true the app will not send emails and will not create calendar events.
✅ How to prove email + calendar work: in the Apps Script editor, pick testNotifications from the function dropdown and press Run. The first run shows a Google authorisation screen — click Advanced → Go to … (unsafe) → Allow. It then really sends one test email to the manager, really creates one calendar event and deletes it again, and prints the result in the Execution log. Nothing is left behind.
