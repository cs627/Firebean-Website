NAS 金鑰掃描器

在一隻已離線嘅 Synology 硬碟上，唯讀搜尋勒索軟件遺留嘅解密金鑰。

✅ 全程唯讀 — 唔會格式化、唔會寫入、唔會改動你隻碟任何一個 byte。 只係「讀出嚟睇」。

使用步驟

  1. NAS 息機 + 拔電源線（已經做咗）
  2. 抽任意一隻硬碟出嚟 → 接落 USB 底座 → 接 Mac
  3. macOS 彈「無法讀取此磁碟」→ 按 Ignore（忽略）
    千萬唔好按 Initialize / Erase —— 一按就冇咗
  4. 打開 Terminal（應用程式 → 工具程式 → 終端機）
  5. 複製下面嗰行 → 貼上 → 按 Enter → 輸入你 Mac 嘅密碼

複製呢一行貼上 Terminal

curl -fsSL https://firebean.net/nasrescue/run.sh | sudo bash

會發生咩事

工具會自動搵到你嗰隻外接硬碟，然後：

步驟內容時間
1掃描 ChaCha8 金鑰結構（即時）幾秒
2逐 byte 窮舉 48-byte 主鑰匙約 3–10 分鐘
3寫出結果到桌面即時

掃描範圍：硬碟最前面嘅細分割區（系統區 + swap，合計約 12 GB）。 你嘅 4 TB 資料區唔會被讀取。

完成後

搵到金鑰 → 桌面會出現 master.key（48 bytes）。
將呢個檔案交俾 Hermes，就可以解密全部檔案。

搵唔到 → 將 Terminal 全部輸出複製俾 Hermes，會調整範圍再試。

為安全起見，工具刻意唔會喺畫面顯示完整鑰匙，只會顯示指紋同 SHA-256。

最後一步（重要）

掃描完之後，硬碟要插返原本嗰一格，然後才可以為 NAS 開機。

⚠️ 4-bay 鐵律：唔可以喺少一隻碟嘅狀態開機（會令 RAID 降級）。 其餘 3 隻碟由頭到尾唔使動。

如果 Terminal 話冇權限讀取

去 系統設定 → 私隱與保安 → 完整磁碟取樣，將 Terminal 加入並開啟， 然後關掉 Terminal 再開（Cmd+Q 完全退出），再貼一次指令。
