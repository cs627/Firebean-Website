WhatsApp 自動化防封禁守則
Firebean — 實戰版 (2026-10)

════════════════════════════════════════
第一層：賬號本身 (養號)
════════════════════════════════════════

1. 新號碼唔可以即刻開工
   新開嘅號碼頭 1-2 星期唔好做任何自動發送。先當普通用戶：加幾個聯絡人、
   傾幾句、發幾張相。WhatsApp 對「一開號就大量發訊」嘅偵測最敏感。

2. 用真實 SIM 卡，唔好用虛擬號
   虛擬號 / 一次性號碼被 ban 率極高。長期用嘅號碼要係實體 SIM。

3. 填好 profile
   有大頭相、有名、有狀態。空白 profile + 大量發訊 = 典型 spam bot 特徵。

4. 唔好頻繁換裝置
   同一個 session 不停重新 link／unlink 手機會觸發風控。要 backup session，
   唔好出事就重新 pair。

5. 明白技術選擇嘅風險
   - 官方 WhatsApp Cloud API：合規，但要 template 審批，唔可以隨意發。
   - 非官方 bridge（Baileys / whatsapp-web.js 等）：靈活，但屬於違反 ToS，
     帳號有被封風險，要用保守策略運行。
   兩者風險模型唔同，唔好當一樣。

════════════════════════════════════════
第二層：發送行為 (最易出事)
════════════════════════════════════════

6. 【最重要】唔好 cold message
   冇雙向溝通記錄嘅號碼，唔可以主動 DM。要等對方先 pm 你（opt-in），
   你先可以回覆。呢條係防封禁嘅第一道閘。

7. 新人每日上限
   每個陌生號碼每日最多回覆 1 次。

8. 全局每日上限
   自動回覆設全日上限（例如 12 次），超出即靜音，交真人處理。

9. 只喺營業時間發
   例如 09:00-23:00。凌晨三點發訊息係極明顯嘅機械人特徵。

10. 要有真人節奏
    唔好同一秒／同一分鐘連環發。每個訊息之間加隨機延遲，
    模擬真人打字、停頓、隔一陣再覆。

11. 唔好重覆同一條訊息
    一模一樣嘅文字連環發去多個 chat，係 WhatsApp spam 偵測嘅核心特徵。

12. 唔好群發廣播
    未經同意嘅大量群發 = 直接高風險。群發要建立喺明確 opt-in 之上。

13. 群組發言要克制
    喺群組度低頻發言。同一個群組唔好短時間內連環貼。

14. 追料要低頻
    跟進（chase）唔可以密集。低頻率 + 真人語氣 + 營業時間。

════════════════════════════════════════
第三層：內容
════════════════════════════════════════

15. 唔好塞大量連結
    短網址（bit.ly 之類）同陌生 domain 係高風險信號。要用完整 https 連結。

16. 唔好有機械人痕跡
    唔好有 markdown（**、```）、JSON、數字列表、程式字眼。
    WhatsApp 係平舖對話，唔係文件。

17. Soft CTA
    唔好 hard sell。聚焦一件事，唔好一次推五樣嘢。

18. 個人化
    每條訊息要有對象嘅名／具體 context。同一模板發 50 人 = 即死。

════════════════════════════════════════
第四層：監控同應變
════════════════════════════════════════

19. 403 = 即停
    收到 HTTP 403 就係明確信號，即刻停止發送，唔好硬試。

20. 被 block / report 係最強警號
    有人封鎖你或者舉報你，風險等級即刻跳升。要停一段時間。

21. 定期備份 session
    出咗事可以還原，唔使重新 pair（重新 pair 本身又係風險）。

22. 「sent 成功」唔等於「真係送到」
    API 回 success 只代表程式送出咗。要確認真係入到對方個 chat。
    唔好靠程式回報嘅 boolean 當事實。

23. 單一 active 連線
    同一個號碼只可以有一個 bridge／session 在線。開多過一個會互相搶線。

════════════════════════════════════════
一句話總結
════════════════════════════════════════

等對方先開口 (opt-in) → 低頻 → 真人節奏 → 營業時間 →
唔重覆 → 唔群發 → 出事即刻停。

核心邏輯：令你嘅號碼「似一個真人用 WhatsApp」，
而唔係「一部機器喺度派傳單」。
