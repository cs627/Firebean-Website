你要做嘅只有 3 件事，之後全部我自己搞掂。

完成後我嘅 pipeline（maps_places_fetch.py）會每日自動抓 10 間分店嘅 Google Maps 評論、分類情緒、寫入 Sheet、更新 Dashboard。你唔需要改任何 code。

1登入 Google Cloud Console

用你嘅 Google 帳號登入（同 dickson@firebean.net 同一組帳號最簡單）。

開啟 Google Cloud Console ↗

2啟用「Places API (New)」

  • 左邊菜單 → APIs & Services → Library
  • 搜尋 Places API (New)（要揀有「(New)」嗰個）
  • 撳入去 → 按藍色 ENABLE 掣
  • 如果叫你揀 project：揀你現有嗰個（即係而家 Gemini 用緊嗰個，個 key 尾號 ux3_-M）
直接開啟 Places API (New) 頁 ↗
⚠️ 唔好揀錯：要 Places API (New)，唔係舊嘅 Places API。 舊版已經停用（我實測過 → REQUEST_DENIED: legacy API not enabled）。

3確認已啟用 Billing（付款）

  • 左邊菜單 → Billing
  • 如果顯示 「This project has no billing account」 → 撳 Link a billing account，加信用卡
  • 如果已經有 billing account（你 Gemini API 用緊）→ 通常已經 OK，唔使做嘢
✅ 好消息：Google 每月有免費額度，而我只會每日抓 10 間分店（每次 1–2 個 API call）， 用量極低（每月約 600–900 calls），正常情況下唔會超出免費額度。
🔒 防止意外收費：建議順手去 Billing → Budgets & alerts， 設一個 US$5 預算警報。超額只會 email 通知你，唔會自動停服務。

4話我知搞掂咗

唔需要 copy 任何 API key 畀我 —— 你現有嗰個 key（…ux3_-M）啟用後就會即刻生效。 喺 Discord 覆我一句「搞掂」，我會自動：

  • 解析 10 間分店嘅 place_id 並永久儲存（ToS 允許）
  • 抓取最新評論 → 情緒分類 → 去重 → 寫入 Sheet 平台類型 = 地圖評論
  • Re-deploy Dashboard，03 Google Maps tab 即刻有料到
  • 將 Maps 步驟加入每日 cron（以後全自動）

❓ 常見問題

為何唔可以直接爬 Google Maps 網頁？

Google Maps Platform ToS §3.2.3(a)「No Scraping」明文禁止提取、複製用戶評論，亦不可建立商戶評論資料庫。用官方 Places API 係唯一合規路線（亦係我幫你揀嘅路）。

要唔要開新 API key？

唔需要。只要喺同一個 project 啟用 Places API (New)，現有 key 就會生效。如果你想隔離風險，可以另開一個新 key 只准 Places API，我照樣可以接。

抓幾多條評論？會唔會好貴？

每間分店每次抓最新 5 條（Places API 上限），10 間分店 = 每日約 20 個 call。一個月約 600–900 calls，遠低於一般免費額度。

會唔會儲存太多評論內容？

我嘅腳本跟 Places 政策：只永久儲存 place_id（明文豁免），其餘即時抓取；並內建 --purge-days 30 選項，可將超過 30 日嘅評論內容自動匿名化（保留日期／星級／情緒）。

如果之後想停？

去 Cloud Console 停用 Places API，或刪走 billing，pipeline 會自動跳過 Maps 步驟，其餘社交聆聽照常運作。
